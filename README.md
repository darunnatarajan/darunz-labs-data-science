# Darunz Labs · Data Science

Data science training material from my live classroom batches: guides, notebooks, datasets and practice work.

If you are in one of my batches, bookmark this repo. I add material as we cover it in class.

---

## What's here now

**Module 7: Statistics Basics** — an illustrated guide covering central tendency, probability, standard deviation, the bias–variance tradeoff, distance metrics and outlier analysis. Every topic has a plain explanation, a picture, a real-world example, Python code and checkpoint questions.

More gets added after each session.

---

## How to open the guide

The guide is an HTML file, so read it here:

`https://darunnatarajan.github.io/darunz-labs-data-science/`

Clicking the `.html` file directly on GitHub shows the code instead of the page. You can also download it and open it in any browser; the interactive demos work offline.

---

## Getting the files

Download the ZIP from the green **Code** button, or:

```bash
git clone https://github.com/darunnatarajan/darunz-labs-data-science.git
```

To get the latest material later:

```bash
git pull
```

Watch the repo (top right) to be notified when I push something new.
